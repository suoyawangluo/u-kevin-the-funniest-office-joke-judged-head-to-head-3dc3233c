One short line about office life for the make.fun bounty
[The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c).

> I called a meeting to discuss why we have too many meetings. It ran twenty minutes over.

The setup is a meeting about too many meetings; the turn is that the meeting itself runs over — the problem under discussion eats its own solution.

`main.ts` writes the line to `/output/entry.txt` (88 code points, 1 line) and verifies it against the gate (1–200 characters, single line, not only whitespace).

Run it with `MAKEFUN_OUTPUT_DIR` set, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`.
